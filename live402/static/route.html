This is the paid routing endpoint.

Agents POST /route when they want 402Signal to check an x402 service immediately before spending. An unpaid request returns HTTP 402 with the $0.01 USDC payment requirements. After payment, 402Signal returns a live route with evidence or an explicit miss.

402Signal does not hold your wallet or pay the selected service.
