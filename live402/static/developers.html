Route before you spend

402Signal checks x402 endpoints before you spend. It compares the payment terms it sees now against your constraints and returns the best match, or a clear reason nothing qualified.

You keep your wallet and keys. 402Signal never pays the selected service for you.

402Signal finds and checks the route. Your application keeps control of its wallet, signs the seller payment, and calls the selected service.

Quick start

Request with real supported JSON only.

Example request 
curl -sS -D - https://402signal.com/route -H 'Content-Type: application/json' -d '{"need":"erc20 token balance","prefer_network":"base"}'
{"need":"erc20 token balance","prefer_network":"base"}

Endpoints

POST /route
Paid routing check. Unpaid calls return HTTP 402.
GET /preview
Unpaid catalog search. Preview uses discovery data.
GET /rails
Supported pay-in rails.
GET /openapi.json
OpenAPI document.
GET /mcp.json
MCP tool document.
POST /mcp
MCP endpoint.
GET /transparency
Human-readable routing history.

Routing fee

$0.01 USDC. The fee pays 402Signal. The selected service payment is separate and stays under caller control.
