Build a /route request

Describe the capability your agent needs, preview current discovery metadata, and compose the exact JSON body for a paid POST /route check.

The capability field accepts free text. The examples below are shortcuts, not a fixed list. Describe any capability in plain English.

Example capabilities

Network lock

Hard policy lock. Discovery and a paid winner must be on this rail from the current observed 402. Any searches all rails.

Prefer network

Weak preference. Ranks this rail first but still searches all rails the network lock allows. Not a filter.

Discovery preview

Search current discovery metadata and show any prior 402Signal observation on file. This does not probe the endpoint again.

Discovery preview uses the capability and discovery network settings above. The route constraints below are included in the paid /route request and are not applied to preview results.
