Why check first

Fresh, not just listed

A catalog row is a candidate. 402Signal checks the current 402 envelope before anyone spends.

Policy actually matters

Network locks and price bounds apply to this live check, not to what a listing still claims.

A miss is a valid answer

If nothing observed matches, 402Signal returns a typed miss instead of an unverified substitute.

Your wallet stays yours
