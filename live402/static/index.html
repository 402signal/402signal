A routing history you can check

402Signal records routing evidence in an append-only Merkle log. Confirmed checkpoints are authorized by a native Falcon-1024 account and anchored on Algorand MainNet. Later changes to the published history can be detected.

To check a specific decision later, securely keep the verification record returned with the paid route. 402Signal does not retain the private evidence or recover it if lost.

Falcon-1024 authorizes the checkpoint transaction. It does not make seller payments or API responses post-quantum secure.
