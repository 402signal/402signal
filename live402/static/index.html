What it is

Fail-closed x402 router. Paid APIs go dark. Catalogs still list them. We probe first. Live means an unpaid HTTP 402 with a parseable payment envelope, not merely reachable. $0.01 USDC on Base, Solana, or Algorand.

Now

POST /route → unpaid HTTP 402; paid hit → live URL plus target contract (method, inputSchema, facilitator); paid miss → typed miss_reason. Free GET /preview /rails /pulse /llms.txt. MCP: route (paid), preview (free). OpenAPI and /.well-known/x402.json. Also in this ship: prefer_network; fail closed on a 402 with no payTo; drop localhost/:param samples; HEAD 200 on machine docs; rank live hits by settlements when we have them.

How it works

Send a need or a URL. We probe. If something answers with a real payable 402, you get that URL and how to call it. If nothing is up, we say why. /preview is free and does not probe. /route is the penny probe.

How to use it

Agents POST https://402signal.com/route with {"need":"weather"}, pay the 402, retry with PAYMENT-SIGNATURE. MCP https://402signal.com/mcp. Docs https://402signal.com/llms.txt. Algorand and Solana are agent/CLI. Hidden Pay Base stays for injected wallets only.
