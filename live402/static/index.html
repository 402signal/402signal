Find a paid API that works right now.

402Signal searches x402 discovery sources across Base, Solana, and Algorand, probes candidate endpoints immediately before spend, and applies the caller's constraints to the payment options returned by those endpoints. It returns a route only when a current observed option qualifies; otherwise it returns a typed miss.

402Signal does not hold the buyer's keys or execute the selected service's payment.

What a paid check does

Current observation

Routing uses the payment requirements observed during this request, not the metadata a discovery source still publishes.

Constraint enforcement

Caller constraints are applied to those observed options before a winner is selected.

Explicit failure modes

When no observed option qualifies, the response is a typed miss that reports why evaluation stopped.

Execution boundary

The caller retains custody of keys, signing, the selected service's payment, and execution of that service.
